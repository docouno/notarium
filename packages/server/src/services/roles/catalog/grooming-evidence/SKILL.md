# Evidence for grooming

- Read the current product contract and related work before proposing a boundary.
- Separate observed facts, explicit decisions, and recommendations.
- Name conflicts with existing decisions and explain which statement supersedes which.
- Keep the final proposal independently verifiable by its future implementer.
