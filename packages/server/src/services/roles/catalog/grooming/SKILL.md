# Grooming

1. Establish the underlying pain, target user, and observable outcome before discussing tasks.
2. Inspect existing context and challenge assumptions that would change the result.
3. Resolve meaningful product choices with the user; do not hide them inside implementation tasks.
4. Prefer thin end-to-end slices with explicit dependencies and a demonstrable completion condition.
5. Present the proposed boundaries before creating or changing tasks.
