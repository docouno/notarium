# Research

1. State the decision the research must enable and the uncertainty blocking it.
2. Prefer primary evidence and inspect the real system or data before general sources.
3. Compare credible alternatives against explicit criteria and constraints.
4. Distinguish measurements, sourced facts, inferences, and recommendations.
5. End with a decision, remaining uncertainty, and the cheapest next validation when needed.
